## 2. 设计变更说明

### 2.1 为什么移除 ID 字段？

| 对比项       | 有 ID 主键         | 复合主键 (推荐) |
| --------- | --------------- | --------- |
| **存储空间**  | 每条记录多 4 字节 + 索引 | 节省空间      |
| **插入性能**  | 需要序列生成器         | 直接插入，更快   |
| **查询效率**  | 需额外索引支持业务查询     | 复合主键天然支持  |
| **数据完整性** | 可能出现逻辑重复        | 业务键天然唯一   |
| **业务语义**  | ID 无业务含义        | 直接反映数据关系  |

### 2.2 复合主键优势

- **天然唯一**：`(指数代码, 交易日期)` 组合唯一确定一条日线数据
- **节省资源**：每条记录减少 4 字节存储 + 索引开销
- **查询优化**：复合主键自动创建聚簇索引，支持常用查询模式
- **数据保护**：防止同一指数同一天插入重复数据
- **逻辑清晰**：主键直接反映业务关系，无需无意义的自增 ID

## 4. 数据库表设计

### 4.1 PostgreSQL 表结构

#### 4.1.1 指数基础信息表 (`index_basic`)

| 字段名           | 数据类型          | 约束                          | 描述             |
| ------------- | ------------- | --------------------------- | -------------- |
| `index_code`  | `VARCHAR(10)` | `PRIMARY KEY`               | 指数代码（如 999999） |
| `index_name`  | `VARCHAR(50)` | `NOT NULL`                  | 指数名称（如 上证指数）   |
| `market`      | `VARCHAR(20)` | `NOT NULL`                  | 市场（如 沪市）       |
| `period`      | `VARCHAR(10)` | `NOT NULL`                  | 数据周期（如 日线）     |
| `adjust_type` | `VARCHAR(10)` | `NOT NULL`                  | 复权类型（如 后复权）    |
| `list_date`   | `DATE`        | <br />                      | 上市日期           |
| `last_update` | `TIMESTAMP`   | `DEFAULT CURRENT_TIMESTAMP` | 最后更新时间         |

#### 4.1.2 指数日线数据表 (`index_daily`) — 复合主键设计

| 字段名          | 数据类型            | 约束                          | 描述             |
| ------------ | --------------- | --------------------------- | -------------- |
| `index_code` | `VARCHAR(10)`   | `NOT NULL`                  | 指数代码（复合主键第一部分） |
| `trade_date` | `DATE`          | `NOT NULL`                  | 交易日期（复合主键第二部分） |
| `open`       | `NUMERIC(10,2)` | `NOT NULL`                  | 开盘价            |
| `high`       | `NUMERIC(10,2)` | `NOT NULL`                  | 最高价            |
| `low`        | `NUMERIC(10,2)` | `NOT NULL`                  | 最低价            |
| `close`      | `NUMERIC(10,2)` | `NOT NULL`                  | 收盘价            |
| `volume`     | `BIGINT`        | `NOT NULL`                  | 成交量            |
| `amount`     | `NUMERIC(20,2)` | `NOT NULL`                  | 成交额            |
| `created_at` | `TIMESTAMP`     | `DEFAULT CURRENT_TIMESTAMP` | 创建时间           |

**主键定义**：

```sql
PRIMARY KEY (index_code, trade_date)
```

**设计说明**：

- 使用复合主键 `(index_code, trade_date)` 替代自增 ID
- 该组合天然唯一：一个指数在一天内只有一条日线数据
- 节省存储空间：每条记录减少 4 字节 + 索引空间
- 提高查询效率：复合主键自动创建聚簇索引，支持常用查询模式
- 数据完整性：防止同一指数同一天插入重复数据

#### 4.1.3 完整建表 SQL

```sql
-- 创建指数基础信息表
CREATE TABLE index_basic (
    index_code VARCHAR(10) PRIMARY KEY,
    index_name VARCHAR(50) NOT NULL,
    market VARCHAR(20) NOT NULL,
    period VARCHAR(10) NOT NULL,
    adjust_type VARCHAR(10) NOT NULL,
    list_date DATE,
    last_update TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 创建指数日线数据表（复合主键设计）
CREATE TABLE index_daily (
    index_code VARCHAR(10) NOT NULL,
    trade_date DATE NOT NULL,
    open NUMERIC(10,2) NOT NULL,
    high NUMERIC(10,2) NOT NULL,
    low NUMERIC(10,2) NOT NULL,
    close NUMERIC(10,2) NOT NULL,
    volume BIGINT NOT NULL,
    amount NUMERIC(20,2) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (index_code, trade_date),
    FOREIGN KEY (index_code) REFERENCES index_basic(index_code)
);

-- 创建日期索引（提高按日期范围查询性能）
CREATE INDEX idx_index_daily_date ON index_daily(trade_date);

-- 可选：创建外键索引（提高 JOIN 查询性能）
-- CREATE INDEX idx_index_daily_code ON index_daily(index_code);
```

## 5. 数据加载方案

### 5.1 数据导入脚本（复合主键版）

```python
import os
import csv
from datetime import datetime
import psycopg2

# 数据库连接参数
DB_PARAMS = {
    'host': 'localhost',
    'port': 5432,
    'database': 'postgres',
    'user': 'postgres',
    'password': 'wy123456'
}

def load_index_data(csv_file, index_code, index_name):
    """
    加载指数数据到数据库
    
    使用复合主键 (index_code, trade_date) 确保数据唯一性
    ON CONFLICT 处理重复数据插入
    """
    conn = psycopg2.connect(**DB_PARAMS)
    cur = conn.cursor()
    
    # 插入指数基础信息
    cur.execute('''
        INSERT INTO index_basic (index_code, index_name, market, period, adjust_type)
        VALUES (%s, %s, %s, %s, %s)
        ON CONFLICT (index_code) DO UPDATE
        SET index_name = %s, last_update = CURRENT_TIMESTAMP
    ''', (index_code, index_name, '沪市', '日线', '后复权', index_name))
    
    # 读取并插入日线数据
    inserted_count = 0
    skipped_count = 0
    
    with open(csv_file, 'r', encoding='utf-8') as f:
        reader = csv.reader(f, delimiter='\t')
        next(reader)  # 跳过表头
        next(reader)  # 跳过字段名行
        
        for row in reader:
            if not row or len(row) < 7:
                continue
                
            try:
                trade_date = datetime.strptime(row[0].strip(), '%Y-%m-%d').date()
                open_price = float(row[1].strip())
                high = float(row[2].strip())
                low = float(row[3].strip())
                close = float(row[4].strip())
                volume = int(row[5].strip())
                amount = float(row[6].strip())
                
                # 插入数据（复合主键冲突时跳过）
                cur.execute('''
                    INSERT INTO index_daily (index_code, trade_date, open, high, low, close, volume, amount)
                    VALUES (%s, %s, %s, %s, %s, %s, %s, %s)
                    ON CONFLICT (index_code, trade_date) DO NOTHING
                ''', (index_code, trade_date, open_price, high, low, close, volume, amount))
                
                if cur.rowcount > 0:
                    inserted_count += 1
                else:
                    skipped_count += 1
                
            except Exception as e:
                print(f"处理行失败: {row}, 错误: {e}")
                continue
    
    conn.commit()
    cur.close()
    conn.close()
    print(f"数据加载完成: {csv_file}")
    print(f"  插入: {inserted_count} 条")
    print(f"  跳过（已存在）: {skipped_count} 条")

def load_index_data_with_update(csv_file, index_code, index_name):
    """

    inserted_count = 0
    updated_count = 0
    
    with open(csv_file, 'r', encoding='utf-8') as f:
        reader = csv.reader(f, delimiter='\t')
        next(reader)  # 跳过表头
        next(reader)  # 跳过字段名行
        
        for row in reader:
            if not row or len(row) < 7:
                continue
                
            try:
                trade_date = datetime.strptime(row[0].strip(), '%Y-%m-%d').date()
                open_price = float(row[1].strip())
                high = float(row[2].strip())
                low = float(row[3].strip())
                close = float(row[4].strip())
                volume = int(row[5].strip())
                amount = float(row[6].strip())
                
                # 插入或更新数据
                cur.execute('''
                    INSERT INTO index_daily (index_code, trade_date, open, high, low, close, volume, amount)
                    VALUES (%s, %s, %s, %s, %s, %s, %s, %s)
                    ON CONFLICT (index_code, trade_date) DO UPDATE SET
                        open = EXCLUDED.open,
                        high = EXCLUDED.high,
                        low = EXCLUDED.low,
                        close = EXCLUDED.close,
                        volume = EXCLUDED.volume,
                        amount = EXCLUDED.amount
                ''', (index_code, trade_date, open_price, high, low, close, volume, amount))
                
                if cur.rowcount > 0:
                    # 通过检查数据是否实际变化来判断是插入还是更新
                    inserted_count += 1
                
            except Exception as e:
                print(f"处理行失败: {row}, 错误: {e}")
                continue
    
    conn.commit()
    cur.close()
    conn.close()
    print(f"数据加载完成: {csv_file}")
    print(f"  插入/更新: {inserted_count} 条")
```

## 6. 示例查询

### 6.1 基本查询

```sql
-- 查询上证指数最近10个交易日数据
SELECT trade_date, open, high, low, close, volume, amount
FROM index_daily
WHERE index_code = '999999'
ORDER BY trade_date DESC
LIMIT 10;

-- 查询上证指数指定日期范围数据
SELECT trade_date, close
FROM index_daily
WHERE index_code = '999999'
  AND trade_date BETWEEN '2024-01-01' AND '2024-01-31'
ORDER BY trade_date;

-- 计算上证指数月度收益率
SELECT 
    DATE_TRUNC('month', trade_date) AS month,
    FIRST_VALUE(close) OVER (PARTITION BY DATE_TRUNC('month', trade_date) ORDER BY trade_date) AS first_close,
    LAST_VALUE(close) OVER (PARTITION BY DATE_TRUNC('month', trade_date) ORDER BY trade_date) AS last_close,
    (LAST_VALUE(close) OVER (PARTITION BY DATE_TRUNC('month', trade_date) ORDER BY trade_date) / 
     FIRST_VALUE(close) OVER (PARTITION BY DATE_TRUNC('month', trade_date) ORDER BY trade_date) - 1) * 100 AS monthly_return
FROM index_daily
WHERE index_code = '999999'
  AND trade_date >= '2023-01-01'
GROUP BY trade_date
ORDER BY month;
```

### 6.2 高级查询

```sql
-- 查询指数历史最高收盘价
SELECT trade_date, close
FROM index_daily
WHERE index_code = '999999'
  AND close = (SELECT MAX(close) FROM index_daily WHERE index_code = '999999');

-- 计算指数5日移动平均线
SELECT 
    trade_date,
    close,
    AVG(close) OVER (ORDER BY trade_date ROWS BETWEEN 4 PRECEDING AND CURRENT ROW) AS ma5
FROM index_daily
WHERE index_code = '999999'
ORDER BY trade_date DESC
LIMIT 20;
```

## 7. 存储优化

### 7.1 分区策略

对于历史数据量大的指数，可以考虑按年份分区：

```sql
-- 按年份分区
CREATE TABLE index_daily (
    -- 字段定义同上
)
PARTITION BY RANGE (trade_date);

-- 创建分区
CREATE TABLE index_daily_2023 PARTITION OF index_daily
    FOR VALUES FROM ('2023-01-01') TO ('2024-01-01');

CREATE TABLE index_daily_2024 PARTITION OF index_daily
    FOR VALUES FROM ('2024-01-01') TO ('2025-01-01');
```

### 7.2 数据压缩

PostgreSQL 支持表压缩，可减少存储空间：

```sql
-- 启用压缩
ALTER TABLE index_daily SET (autovacuum_enabled = true, toast.autovacuum_enabled = true);

-- 对现有表进行压缩
VACUUM FULL ANALYZE index_daily;
```

### 9.4 分表设计优势

1. **查询性能**：单表数据量减少，查询更快
2. **维护便利**：单个标的可独立备份、清理
3. **并发优化**：不同标的操作互不干扰
4. **扩展性强**：新增标的只需创建新表
