# 股票表设计文档

## 1. 设计背景

根据 `d:\AI量化999\data\300` 目录中的数据文件，设计股票数据存储表结构。数据文件包含上海证券交易所（SH）和深圳证券交易所（SZ）的股票历史交易数据。

## 2. 数据文件分析

### 2.1 文件命名格式

数据文件命名格式为：`{交易所代码}#{股票代码}.xls`

- 交易所代码：
  - SH：上海证券交易所
  - SZ：深圳证券交易所
- 股票代码：6位数字，如 600000、300001 等

### 2.2 数据结构

每个数据文件包含股票的历史交易数据，字段包括：

| 字段名 | 描述 | 格式 |
|-------|------|------|
| 日期 | 交易日期 | YYYY-MM-DD |
| 开盘价 | 当日开盘价格 | 浮点数 |
| 最高价 | 当日最高价格 | 浮点数 |
| 最低价 | 当日最低价格 | 浮点数 |
| 收盘价 | 当日收盘价格 | 浮点数 |
| 成交量 | 当日成交数量 | 整数 |
| 成交额 | 当日成交金额 | 浮点数 |

## 3. 表结构设计

### 3.1 表名规则

表名格式：`stock_{周期}_{股票代码}`

- 周期：
  - daily：日K数据
  - weekly：周K数据
  - monthly：月K数据
- 股票代码：6位数字，如 600000、300001 等

例如：
- 股票代码 600000 的日K表名为 `stock_daily_600000`
- 股票代码 300001 的日K表名为 `stock_daily_300001`

### 3.2 字段设计

| 字段名 | 数据类型 | 约束 | 描述 |
|-------|---------|------|------|
| date | DATE | PRIMARY KEY | 交易日期 |
| open | DECIMAL(10,4) | NOT NULL | 开盘价 |
| high | DECIMAL(10,4) | NOT NULL | 最高价 |
| low | DECIMAL(10,4) | NOT NULL | 最低价 |
| close | DECIMAL(10,4) | NOT NULL | 收盘价 |
| volume | BIGINT | NOT NULL | 成交量 |
| amount | DECIMAL(20,4) | NOT NULL | 成交额 |

### 3.3 索引设计

- 主键索引：`date` 字段作为主键，确保每个日期的数据唯一
- 无其他索引需求，因为主要按日期查询

## 4. 数据导入策略

1. **文件解析**：
   - 使用 pandas 读取 XLS 文件
   - 跳过表头行（第一行）
   - 重命名列名以匹配表结构

2. **数据清洗**：
   - 处理空值和异常值
   - 格式化日期为 YYYY-MM-DD 格式
   - 确保数值类型正确

3. **表创建**：
   - 对于每个股票代码，创建对应的表
   - 检查表是否存在，不存在则创建

4. **数据插入**：
   - 使用批量插入提高效率
   - 跳过已存在的日期数据（避免重复）

## 5. 示例表结构

### 5.1 股票日K表 `stock_daily_600000`

```sql
CREATE TABLE stock_daily_600000 (
    date DATE PRIMARY KEY,
    open DECIMAL(10,4) NOT NULL,
    high DECIMAL(10,4) NOT NULL,
    low DECIMAL(10,4) NOT NULL,
    close DECIMAL(10,4) NOT NULL,
    volume BIGINT NOT NULL,
    amount DECIMAL(20,4) NOT NULL
);
```

### 5.2 股票日K表 `stock_daily_300001`

```sql
CREATE TABLE stock_daily_300001 (
    date DATE PRIMARY KEY,
    open DECIMAL(10,4) NOT NULL,
    high DECIMAL(10,4) NOT NULL,
    low DECIMAL(10,4) NOT NULL,
    close DECIMAL(10,4) NOT NULL,
    volume BIGINT NOT NULL,
    amount DECIMAL(20,4) NOT NULL
);
```

## 6. 注意事项

1. **数据完整性**：
   - 确保每个股票表的 `date` 字段唯一
   - 确保所有数值字段非空

2. **性能优化**：
   - 对于大量历史数据，建议使用批量插入
   - 定期优化表结构和索引

3. **扩展性**：
   - 如需添加新字段，应保持向后兼容
   - 考虑未来可能的数据分析需求

4. **数据备份**：
   - 定期备份股票数据，防止数据丢失

## 7. 总结

本设计文档基于 `d:\AI量化999\data\300` 目录中的数据文件结构，设计了股票历史交易数据的存储表结构。通过为每个股票创建独立的表，并按照周期进行分类，实现了数据的隔离和高效查询。表结构设计合理，字段类型选择恰当，能够满足股票数据的存储和分析需求。
