# 交易策略文档：均线牛熊（MA200）+ MA60 上下穿

## 1. 策略概述

本策略用于对指数或标的进行“趋势/震荡”意义上的交易决策，其中趋势判定采用长期均线过滤，交易信号采用中期均线交叉：

- 第一条件（牛熊环境）：收盘价与 **MA200** 的关系
- 交易触发（买卖点）：收盘价与 **MA60** 的上穿/下穿

策略特点：

- 仅做多，不做空
- 熊市环境强制空仓（降低长期回撤风险）
- 规则清晰、可解释、适合用于指数趋势跟随的基准策略

## 2. 适用标的

当前默认用于指数回测（来自本地数据库）：

- 沪深300：`sh000300`（库表：`index_000300`）
- 中证500：`sh000905`（库表：`index_000905`）
- 创业板指数：`sz399006`（库表：`index_399006`）

## 3. 数据源与数据要求

### 3.1 数据来源

- 使用 akshare 获取指数日线行情
- 优先从本地 SQLite 数据库读取；若缺少指数表则自动拉取并写入后继续回测

### 3.2 数据字段要求（日线）

必须包含以下字段：

- `date`
- `open`
- `high`
- `low`
- `close`
- `volume`

## 4. 指标定义

### 4.1 MA200（牛熊判定）

- `MA200 = SMA(close, 200)`
- 牛市：`close > MA200`
- 熊市：`close <= MA200`

### 4.2 MA60（交易判定）

- `MA60 = SMA(close, 60)`
- 上穿：`close` 从下向上穿越 `MA60`
- 下穿：`close` 从上向下穿越 `MA60`

## 5. 交易规则（核心逻辑）

### 5.1 牛熊过滤（第一条件）

- 若 `close <= MA200`：
  - 不允许开仓
  - 若已有持仓：**强制平仓**

### 5.2 牛市内的买卖点

在满足 `close > MA200` 的前提下：

- 买入信号：`close` **上穿** `MA60` 且当前无持仓 → 开多
- 卖出信号：`close` **下穿** `MA60` 且当前有持仓 → 平仓

### 5.3 成交与仓位

- 以 backtrader 的 `trade_size` 表示每次交易的数量（默认 1）
- 回测默认按收盘价序列生成信号；实际成交由 backtrader 撮合机制处理

## 6. 回测参数（可配置）

建议参数解释（与回测入口一致）：

- 牛熊均线周期(MA200)：`ma_regime_period`，默认 `200`
- 交易均线周期(MA60)：`ma_trade_period`，默认 `60`
- 每次交易数量：`trade_size`，默认 `1`
- 手续费率：`commission_rate`，默认 `0.0`
- 初始资金：`initial_cash`，默认 `100000.0`
- 回测区间：`start_date` / `end_date`
- 自动补齐数据：`auto_fetch_if_missing`，默认 `True`

## 7. 输出结果与报告说明

### 7.1 回测结果结构（主要字段）

- `trade_records`：交易记录（含时间、动作、价格、数量、原因）
- `equity_curve`：权益曲线（时间、权益）
- `report`：核心绩效指标（收益率、回撤、夏普、胜率等）
- `markdown_report_path`：Markdown 报告输出路径（如传入输出路径）

### 7.2 Markdown 报告内容

报告包含：

- 策略参数（中文）
- 核心指标（中文，百分比类指标保留小数点后两位并以 % 展示）
- 全部交易记录（中文原因说明）

## 9. 运行方法（示例）

### 9.1 批量回测三大指数并输出 Markdown 报告

下面示例会把报告输出到 `reports/ma_regime/`：

```python
import os
from core.backtest.backtester import BacktestEngine

engine = BacktestEngine()
out_dir = os.path.join("reports", "ma_regime")

engine.run_ma_regime_backtest_batch(
    ["sh000300", "sh000905", "sz399006"],
    start_date="2018-01-01",
    end_date=None,
    initial_cash=100000.0,
    commission_rate=0.0,
    ma_regime_period=200,
    ma_trade_period=60,
    trade_size=1,
    include_bias_check=False,
    markdown_output_dir=out_dir,
    auto_fetch_if_missing=True
)
```

## 10. 风险提示

- 均线策略属于滞后指标，震荡市中可能频繁交易导致胜率偏低
- 若实际交易存在滑点/手续费，绩效会弱于理论回测
- 指数成分及编制规则变化可能影响长期回测可比性
