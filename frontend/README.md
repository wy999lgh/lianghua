# 量化交易前端项目

## 项目简介

这是一个基于Vue.js的量化交易前端项目，主要功能包括：
- ETF K线图表展示
- 网格交易策略回测
- 交易历史数据可视化
- 收益走势分析

## 技术栈

- Vue.js 3
- Element Plus
- Lightweight Charts
- ECharts
- Axios

## 项目结构

```
frontend/
```

## 安装和运行

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

### 3. 构建生产版本

```bash
npm run build
```

## 主要功能

### K线图表
- 支持日线、周线、月线切换
- 可调整数据条数（100条、300条、500条、1000条）
- 显示MA5、MA10、MA20、MA30均线
- 支持交易信号标记（买入/卖出）
- 显示数据统计信息（总记录数、日期范围、价格区间、平均成交量、最新收盘价）

### 回测功能
- 支持设置回测参数（开始日期、结束日期、基准价格、上步长、下步长、初始资金、买入数量、卖出数量、最大持仓、最小持仓）
- 执行回测后显示详细结果（总收益率、年化收益、总资产、持仓市值、可用资金、最大回撤、夏普比率、交易次数）
- 显示收益走势图（策略收益与基准收益对比）
- 显示交易历史明细

## 注意事项

1. 前端项目需要与后端服务配合使用，后端服务默认运行在 `http://localhost:8001`
2. 确保后端服务已启动，否则无法加载数据
3. 本项目使用的是模拟数据，实际使用时需要替换为真实的数据源
4. 如需修改后端服务地址，请修改 `vite.config.js` 中的代理配置
